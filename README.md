# 鯉魚十球秀｜3D 排練舞台

繁體中文、純前端的十球表演編排工具。使用 Three.js、OrbitControls、SortableJS、TypeScript 與 Vite，不連接實體機器人。

## 啟動與建置

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
npm test
npm run build
```

開啟終端顯示的本機網址。`dist/` 是建置產物，請以 HTTP 靜態服務開啟，不要直接雙擊 HTML。Vercel 使用建置命令 `npm run build`、輸出目錄 `dist`。GitHub Pages 可部署 `dist` 內容，Vite 已使用相對資源路徑，支援子目錄。

## 操作

- 左側舞台：單指或滑鼠左鍵旋轉，雙指縮放與平移，滾輪縮放、右鍵平移。下方按鈕切換視角。點球可查看該球位置、停點及出發順序。
- 節目庫：拖卡片加入節目單，或按「加入」。長按後拖曳方便觸控操作。
- 節目單：使用把手拖曳，或按上移、下移。每張卡獨立調時長，可重複加入、刪除。
- 編輯即暫停並回到 0 秒，自動換位計入總長。預覽包含該卡前的換位，段尾自動暫停。
- 節目單儲存於此瀏覽器的 localStorage；無痕模式、清除網站資料或更換網址可能無法保留。

## 修改方式

- `src/timeline.ts`：節目名稱、預設時長、動作摘要、起始隊形與動作函式。位置以距同側站位線的公尺數表示；右側顯示座標為 `10-d`。新增節目需同步更新初始隊形、動作、字幕及驗收測試。
- `src/main.ts`：舞台寬 10 公尺、深 8 公尺；五條球道的 z 座標為 `7 - lane * 1.5`。角色與球以相同編號對應，前五個是左隊、後五個是右隊。
- `src/style.css`：版面、隊色、卡片與平板斷點。

時間軸先編譯為表演段及 2 秒換位段，再由 `sample(segments, time)` 直接求出球位。相機使用獨立狀態。倒數最短 5 秒，其餘節目最短 1 秒；每張卡上限 300 秒。

## 驗證

`npm test` 檢查預設 60 秒、25／43／45.5 秒畫面、開花移至首段的換位與位置連續性，以及獨立時長縮放。`npm run build` 包含 TypeScript 型別檢查。

實際平板的雙指手勢與拖曳手感仍建議在目標裝置上確認。

視覺改為明亮主題與 BOLT 風格透明球，新增彩虹 LED、像素球號、短距離地面燈光、衝線尾光與可切換後製光暈。「光暈：自動」以視窗寬度及硬體核心數判斷；它不是實際 FPS 測量，低效能裝置可手動關閉。

`sample()` 現在回傳 `targets`、`colors`、`brightness`、`finishLit`，渲染不另外累積這些狀態。測試包含目前小動作停點、字幕週期、倒數紅黃綠與謝幕亮燈。新增節目與視覺規則見規格書第 8 節。

保留原版及節奏秀兩套 60 秒；本次未加入音樂、隊員姓名介紹與跨球道圖案。

## 鯉魚十球秀（新）：標準動作範例（2026-11-25，Claude）

節目單上方新增「🐟 鯉魚秀（新）」範本，60 秒共 9 段：前進 → 後退 → 拉鍊穿插 → 圍圈圈 → 繞圈圈 → 到中間集合 → 排魚造型 → 到前面排一直線 → 謝幕。

- 這是給孩子看的「標準動作」：球走整齊的路線，最小球距 0.75 m、最高速約 1.5 m/s（中低速）。實際操作做不到也沒關係，可愛就好。
- 這 9 段在整個舞台自由走位：播放時會收起球道，地上只亮出這段要用的膠帶記號（中線記號、拉鍊半條路、圓圈、✕ 魚形點、前方直線），「排魚造型」時老師的鯉魚道具會放到舞台中間。
- 畫面右上角的提示卡會寫「這段要做什麼」和「做不到也沒關係」。
- 新卡片（`src/freeShow.ts`）可和原本的球道卡片混排；換位會自動補 2 秒。原版與節奏秀範本保留，第一次開啟仍載入原版。

## 再加三套標準動作範本（2026-11-25，Claude）

節目單上方的範本區現在有四套自由走位節目，每套 60 秒，都附地上膠帶記號和「這段要做什麼／做不到也沒關係」提示卡：

- 🐟 鯉魚秀：舞台中間一開始就鋪著一條大鯉魚（Lester 提供的圖），整套圍著牠演：燈亮出發、游到鯉魚身邊、跟鯉魚打招呼、繞著鯉魚游、鯉魚吐泡泡、到中間集合（進出兩次）、貼著鯉魚排魚形、跟鯉魚一起呼吸、到前面排一直線、謝幕。
- 🌈 彩虹花園：撒種子、發芽、往中間長、排成大花、花瓣變色、花開花合、到前面排一排、謝幕。以燈光為主，移動最少。
- 🚂 小火車開動：排隊上車、鳴笛出發、繞舞台一圈、分成兩列、兩列火車交會、進站停好、謝幕。
- 🎆 新年煙火會：到中間集合、倒數 3、2、1、小煙火、中煙火、大煙火、煙火散落、到前面排一排、謝幕。

節目寫在 `src/shows/`（`kit.ts` 共用工具、`koi.ts`、`more.ts`），`src/freeShow.ts` 是總表。每張卡片列出起點、終點、動作、燈光、字幕、提示與膠帶記號；測試會檢查每套 60 秒、不出界、球距至少 0.7 m、最高速不超過 1.6 m/s。

舞台後方與兩側的ㄇ字型是一群伴舞學生（`src/stage/dancers.ts`），跟著節目時間每 4 秒換一種舞步；原本的背板與彩旗已移除。
